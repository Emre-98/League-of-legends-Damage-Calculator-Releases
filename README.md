# League of Legends Damage Calculator — Downloads

This repository hosts public Windows installers and signed update files for League of Legends Damage Calculator. Source code is maintained separately in a private repository.

Download installers from [Releases](https://github.com/Emre-98/League-of-legends-Damage-Calculator-Releases/releases). No installer has been published yet.

The calculator supports selected single-target damage and DPS scenarios. Some mechanics remain partially modeled; results are not a guarantee of exact in-game behavior. The application does not interact with the Riot Client or League of Legends.

Future signed releases will include an updater manifest (`latest.json`). Updater signing is separate from Windows code signing.
